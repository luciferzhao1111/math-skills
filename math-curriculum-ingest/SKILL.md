# 题库导入与母题粗提炼（math-curriculum-ingest）

**一句话**：把一堆题喂进来 → 脚本**粗聚类** → 产出**复核模板** → **人来定稿母题**。

---

## ⚠️ 一、先说清楚它**做不到**什么（重要，别抱错预期）

1. **"导入题库就自动出母题" —— 不成立。**
   脚本靠**文本相似度**聚类。它能认出"同一道题只换了数字"，
   但**认不出"换了情境的同一母题"**（那恰恰是"变式"的定义）。
   > 例：「求红球概率」和「求抽到男生的概率」是同一个母题，
   > 但文本长得完全不一样 —— 脚本**永远不会**把它们聚到一起。

2. **聚类结果只是"候选"，不是"答案"。**
   所有簇默认标 `verified: false`。**没有人工过一遍，这份清单不能用。**

3. **版权红线**：**教材不能打包分发**；**真题建议只存"锚点"（出处），不复制题干**。
   本技能只处理"你自己有权处理"的题目。

> **为什么还值得做**：它可以替你挡掉 80% 的机械比对 ——
> 几百道题里，"哪些是同一道题的变体"人眼翻一天，脚本几秒钟给你一叠候选，
> **你只需做最后那点判断。**

## 二、什么时候用 / 不用

| 用户说 | 走这条 |
|---|---|
| "我攒了一堆题，帮我整理下 / 归类" | 完整流程（§三） |
| "这几百道题里有没有重复的？" | `ingest.py` 跑一遍，看高相似簇 |
| "帮我把这些题提炼成母题" | 脚本粗聚 + **你/LLM 逐簇定稿**（§三 第 3 步） |
| "出一份卷 / 批改 / 画知识地图" | **不用本技能** |

## 三、流程（三步，第三步不可省）

### 第 1 步：导入

把题目放成**一题一个 `.txt`**（文件名当题号），或一个 `.jsonl`（每行 `{"id","stem"}`）：

```
raw/
├── q1.txt      ← 解方程 x^2-5x+6=0。
├── q2.txt
└── ...
```

> **有 LaTeX 就写进去**（`$x^{2}-5x+6=0$`）—— 公式里的数字也是判重的依据。

### 第 2 步：粗聚类

```bash
python3 scripts/ingest.py raw/ --out clusters.json --report clusters.md
```

输出两个文件：
- `clusters.json` —— 结构化候选簇（代表题、成员、簇内平均相似度、`needs_human_check`）
- `clusters.md` —— **复核模板**：每簇一张卡，留出「是同一个母题吗？☐是 ☐否 ☐拆分」让人填

> **`needs_human_check`**：簇内**最弱一对**的相似度低于阈值 —— 说明这簇可能是
> **链式误聚**（A≈B、B≈C，但 A 和 C 根本不是一回事）。**重点看这些簇。**

### 第 3 步：人工定稿（**不可省**）

逐簇判断，然后在 `clusters.json` 里：
- **是同一母题** → `verified: true`，填母题名
- **不是** → 拆开（把成员重新分组）
- **孤题** → 逐题判断"是不是要新建母题"

> **孤题 ≠ 无用。** 一道从没见过的题**可能就是它自己那个母题**。
> 脚本归不进簇，恰恰因为题库里还没有它的同类。

### 第 3.5 步：母题卡的 8 个字段（定稿后必填）

母题不是一个名字，是一张能反复出题的卡。缺字段的卡，出卷时用不上：

| # | 字段 | 填写要点 |
|:--:|---|---|
| 1 | `concept_family` | 用**教材章节**锚定（如"必修二 第9章 空间直线与平面"），不写"高考考点"。对不上教材的（如新定义压轴）标 `derived: true` 并注明依赖的家族 |
| 2 | `sub_skills` | 3–6 条**可单独判错**的动宾短语。反例「掌握余弦定理」（判不了）；正例「由两边及夹角求第三边」 |
| 3 | `canonical_setup` | **纯槽位，禁具体数值**：`P-ABCD 中，PA⊥平面ABCD，底面为[正方形\|矩形]，求[体积\|线面角]` |
| 4 | `typical_traps` | 3–5 条，格式 `错法 → 触发条件 → 可观测证据`（证据要能指出"错的人在卷面上写成什么样"） |
| 5 | `carrier_set` | 历年载体，**分两级**：`格`（教材级分类，如"锥·多面体"）／`形态`（解题动作，如"三棱锥(侧棱⊥底)"） |
| 6 | `difficulty_ref` | 题位 ＋ 难度区间 |
| 7 | `variant_ladder` | 4 档，**每档只写"扰动什么"**，不写题 |
| 8 | `chain_type` | 设问链型（求值/证明/存在性/范围/充要）＋历年高频序列 |

**禁止进卡**：题干原文、答案、具体数值。**这是切断"照抄旧题"的唯一切实手段。**

**年份不要单独建列**：年份信息本来就在"真题锚"文本里（如 `2023春·解17`），
统计时**脚本从锚文本派生**即可，不落表 —— 多建一列就多一处会漂的真相源。

**载体别混解法**：`几何法/向量法` 是**解法**，不是载体。混进 `carrier_set` 会让覆盖率算错。

## 四、聚类是怎么算的（透明，便于你调参）

```
相似度 = 0.5 × 文本序列相似度(difflib) ＋ 0.5 × 关键词 Jaccard
```

- **归一化**：剥掉标点空白，只留中日韩文字与数字字母（与出卷闸门**同一套口径**，
  保证"查重"和"聚类"判的是同一件事）。
- **聚类方式**：单链（连通分量），阈值默认 `0.55`，用 `--thresh` 调。
  - 調**低** → 聚得更狠（宁可多聚，交人拆）
  - 調**高** → 只聚非常像的

> **单链的已知倾向**：会把"一条链"上首尾并不相似的题串进同簇。
> 对**粗筛**可接受（宁可多聚、交人拆），报告里用 `needs_human_check` 标出来。

## 五、脚本

```bash
python3 scripts/ingest.py <raw目录> [--out clusters.json] [--report clusters.md] [--thresh 0.55]
python3 scripts/ingest.py selftest        # 内置自检（5 项）
```

自检里专门验证了**"不相干的题不能误聚"**和**"每题都被处理（簇成员＋孤题 = 总数）"** ——
避免"看起来跑了、其实漏了一半题"。

## 六、和其他技能怎么配合

```
math-curriculum-ingest   →  粗聚类 + 人工定稿 = 母题清单（含 id）
        ↓
math-knowledge-atlas     →  把母题按前置关系连成图
        ↓
math-mastery-scheduler   →  决定每个母题练到什么程度
        ↓
math-paper-forge         →  出卷（每道题标上母题 id）
```

**关键：母题 id 要一路沿用**（`clusters.json` 里定稿的 id ＝ 出卷时的分组标签）。
