# 调度规则全文

本文件按需加载。SKILL.md 里是梗概，这里是边界与"反直觉"提醒。

## 一、最反直觉的三条（先读这个）

1. **"连对 2 次"不等于"该升档"。**
   连对 2 次只是**进入探测（Probe）**。正式升档还要「探测通过 ＋ 独立复现 ＋ 同级迁移 ＋ 延迟复现」。
   > 直觉是"做对两次就加难度"；但这会把**运气**当成**能力**。加难度的代价是挫败感（不可逆），
   > 而多等几道题的代价只是几分钟 —— **不对称，所以宁可多等。**

2. **"做错了"不等于"该降档"。**
   单次概念/思路错只触发**预警**（不降档）；要**同档累计 2 次**才降。
   > 若升档要"连对 2 ＋ 探测 ＋ 三证据齐"、降档却只要"单次错"，**档位会系统性下沉** ——
   > 最后卡在低档出不去。

3. **"探测题错了"不等于"档位要退"。**
   探测题（Probe）只是**侦察**：错了就按错因追加专项，**正式档位一动不动**。
   > **只有当前档判定题（Judgment）影响正式档位。**

## 二、完整规则表（针对当前档判定题）

| 触发条件 | 动作 | 连对 | 档位 |
|---|---|---|---|
| 判对（连对 1 次） | 加 1 道**变式**巩固 | 1 | 不变 |
| 同档连对 2 次 | **进入探测（Probe）** | 2 | **不变** |
| 探测通过 **且** E2＋E3＋E4 齐 | 正式 **+1★** | 清零 | +1 |
| 判错 · **计算失误** | **冻结** ＋ 限时计算专项 | 清零 | 不变 |
| 判错 · **概念混淆/思路卡壳**（本档首次） | **预警**（不降）＋ 补台阶 ＋ 1 道同档补强 | 清零 | 不变 |
| 判错 · **概念混淆/思路卡壳**（本档累计 ≥2） | **−1★** ＋ 回前置单点题 | 清零 | −1 |
| 已到 **★** 仍错 | 退回**课本概念 ＋ 教材例题** | 清零 | 不变 |

**三条硬约束**：
- **连对**：同一难度档下**判定题**连续全对的次数；**升档后从 0 重计，跨档不累计**。
- **升档依据必填**：`+1★` 必须写清「同级连对次数 ＋ 最后一次证据（日期·题号·结果）」。写不出 → 不许升。
- **`level` ≠ `target_level`**：连对很多次只说明"当前档稳"，**不等于达标**。

## 三、四档证据与"已掌握"的尺子

| 证据 | 含义 | 怎么取 |
|---|---|---|
| **E1 本轮通过** | 刚做完做对（可能看过提示/解析） | 判卷时记 |
| **E2 即时独立复现** | 换题、**无人提示**、独立做对 | 下一份卷里换题考 |
| **E3 同级迁移** | 换数字/问法/情境后**独立**做对且关键理由对 | 再下一次 |
| **E4 延迟复现** | 隔 ≥7 天再做**仍**独立做对 | 排到后面 |

**"已掌握"＝ 达标档 ＋ 连对 ≥3 ＋ E2 ＋ E3 ＋ E4。** 与**销号条件同一把尺**。

> **⚠️ "看了解析再做对" 不算 E2。** 只要给过提示/看过解析，这一次就只能是 E1。
> 这是证据体系最容易注水的地方。

**语言纪律**：描述掌握**只用 E1–E4 四个词**。**禁止**"全部攻克""已掌握"这类断言 ——
`E1 通过` 离 `E2` 还差一次"独立"。

## 四、状态与它的"回流"

状态**由证据实时计算**，不是固定流水线：

```
攻坚中 ⇄ 待补台阶 ⇄ 纠正中 ⇄ 保温 ⇄ 已掌握
```

允许的**回流**：`攻坚中 → 待补台阶`（本档出错）、`保温 → 回流处理`、
`纠正中 → 重新补强`、`已掌握 → 回归`（延迟抽查又错）。

**「纠正中」的退出条件**（防长期挂起）：
- E4 通过 → 攻坚中
- E4 失败且概念/思路错 → 待补台阶
- E4 失败且计算错 → 档位保持 ＋ 计算专项

## 五、时间参数（**不是定律**）

```
新考点：第 1 天 → 第 3 天 → 第 7 天 → 第 14 天 → 结课抽查
```

> ⚠️ **这组天数是"默认参数"，不是学习科学常数。**
> 间隔学习的实证（分散复习优于集中突击、检索练习优于重读）支持"**间隔与交错总体有利**"，
> 但**不支持**把某组固定天数当成对所有人、所有内容都成立。
> **可依实测效果与剩余时间调整。**
> 「同一考点最多复现 3 次」同理 —— 那是**资源保护阈值**，不是规律。

> ⚠️ **复现周期 ≠ 难度升降。** 这组天数只决定"**什么时候再考**"；
> **正式升降档只执行 §二**。**禁止**"答对就拉长间隔、答错就缩短"这类简化规则的**反向误用**
> （即：不能用复现结果直接跳档）。

## 六、复现九条铁律（违者不得发卷）

见 SKILL.md §5.2。最容易违反的三条：

- **铁律 4（形式阶梯）**：第 1 次换数字、第 2 次换问法/表征、第 3 次换情境＋并列辨析。
  **禁止连续两次都用"换数字"。**
- **铁律 7（新鲜感配额）**：每份卷 **≥50% 的题**是没做过的考点或情境。
  > **学生反感的不是重复，是"看不到进展的重复"。**
- **铁律 8（订正与复现分离）**：**原题重做只在订正环节**，**不进练习卷**。
  > 原题重做＝识别熟悉文本，会制造"我会了"的错觉。

## 七、事故记录（为什么这些规则存在）

1. **10 个考点全部重合**：某天发的两份卷考点集完全重叠，学生原话"很多题目反复在做，烦死了"。
   → 根因：把"复现"做成了"换个数字再考一遍"，间隔压成 0 天。
   → 补丁：**同日同考点禁令** ＋ **复现形式阶梯**。

2. **"没题可出"**：因为没有统一的母题清单，出卷时无从取题，一度"没题可出"。
   → 补丁：建**母题总表**（考点 × 难度档），出卷从表里取。

3. **升档拍脑袋**：出现"昨天做对→今天升档"，无任何依据记录。
   → 补丁：**升档依据必填**（同级连对次数 ＋ 最后一次证据）。

4. **同卷既升又降的矛盾**：同一份卷里，AI 既判定升档又判定降档，自创规则。
   → 根因：没区分"判定题"与"探测题"。
   → 补丁：**判定粒度** —— 一份卷、一个考点只产生**一个档位判定事件**。

---

## 八、调度优先级（不可颠倒）

```
安全性 ＞ 闭环完成 ＞ 独立复现 ＞ 迁移 ＞ 升档 ＞ 题量
```

**"加难度"排在最后。** 宁可少练两道题，也不能跳过独立性验证去升档。
