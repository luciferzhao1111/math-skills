# 版式硬规则 v4.19（数学卷 PDF · 可执行版）

> **定位**：把「排版工程规则」压成**给 AI 直接执行的判据**。每条都写成"怎么做 / 怎么判 / 踩过什么"。
> **上位文档**：规则全集 v4.19 §8.0（本文件是它的执行摘要，冲突时以 §8.0 为准）。
> **一句话**：**版式是公共正本，出卷脚本只换数据。**

---

## 0. 引擎口径：渲染层按环境选型（v4.19 定）

| 层 | 要求 |
|---|---|
| **内容层** | 题目数据、母题号、分值、限时常量 —— **唯一真相源，跨环境相同** |
| **判定层** | 闸门 G0–G9、配速校验、回归检查 —— **同一套判据，跨环境相同** |
| **渲染层** | **按环境选型**：本地 Windows 用 `typeset/`（HTML→MathJax→Chrome→PyMuPDF）；无 Chrome/无 L: 盘的环境用 `ws.py`（reportlab+matplotlib）等效链路 |

**禁止写成"某引擎唯一正本、其他作废"** —— 那会让没有该环境的一方**无 PDF 可出**。
可换的是渲染器；**不可换的是数据、常量、版式纪律与判定口径**。

---

## 1. 交付形态（4 条）

| # | 规则 | 判据 |
|:--:|---|---|
| 1.1 | PDF 是唯一交付形态 | 不得只给 Markdown；"我要能直接打印的东西" |
| 1.2 | **答案独立成 PDF**（`_答案.pdf`） | 页脚"共 Y 页"只数卷子，打印张数才对得上；答案页从不打印，独立文件永不误印 |
| 1.3 | 页脚 = `文件名 · 第 X 页 / 共 Y 页` | 散页混在一起时只写"第 3 页"无法判断归属 |
| 1.4 | **事前材料禁令** | 学生未作答前**只交**卷子＋答案；禁卷前导学、预防性台阶页、做题前通读讲解 |

> 1.4 的成本依据：孩子时间是唯一成本；实测**看详解不到 5 分钟、第 2 页起基本不看**，事前泛讲等于零收益＋浪费 token。

## 2. 字体与公式（6 条）

| # | 规则 | 踩过的坑 |
|:--:|---|---|
| 2.1 | 中文统一 **Noto Sans SC** | DengXian 太细、SimHei 太黑，混排发虚 |
| 2.2 | 字重**锁 Medium 500**（`font-variation-settings:"wght" 500`） | 裸 `"Noto Sans SC"` 会解析到 **Thin** 实例 → 卷面发虚、打印发淡 |
| 2.3 | 字体**自动子集化** | 单卷 18MB → 约 400KB；不走统一 render 会体积失控 |
| 2.4 | 公式**去粗**（`font-weight: normal`） | 公式黑体一印就糊 |
| 2.5 | 行内**禁 `\dfrac`**，写 `1/2`、`\sqrt{2}/2` | `\dfrac` 高达 34pt，行距常只有 21–27pt → 必然骑线 |
| 2.6 | **禁 Unicode 上下标字符**（₀–₉），一律 `<sub>/<super>` | 中文字体无这些字形 → 印成方框 |

**另外两条 LaTeX 纪律**：
- **含反斜杠的字符串必须 raw**（`r"..."`）。`\bar`/`\frac`/`\v` 落进非 raw 字符串 → 变成退格/换页字符，PDF 里显示 `Math input error` 或直接解析崩。
- 每写完一批公式，**grep 一遍 `\text{`、`\mathbf{` 里有没有中文** —— mathtext 无中文字形，会印成方框（G9 硬红线）。

## 3. 填空线与选择题（4 条）

- **题干结尾**用弹性线（`fill()`）：撑满本行；本行放不下 → **整块移到下一行**，不得折成半截。
- **题干中间**用全角下划线（`blank()`）：`nowrap`，不可拆。
- **禁固定宽度盒子**：实测会整块掉行、断成两截。
- 长度按答案给足：1–2 字符 → 6 字位；3–5 字符（分数/根号）→ 8；范围/不等式 → 10。**放不下由弹性机制收短，不手工上调**。

**选择题**：
- 自适应行排：**短选项一行 4 个 / 中等 2 个 / 长选项 1 个**；判据按渲染宽度实测（最宽项 × n ＋ 间距 ×(n−1) ≤ 版心宽，n 优先 4）。
- 用**无框栅格**排布（没有线，就不可能"公式骑线"）。
- 题干末尾给长横线填字母，并印明「（填选项字母）」；**禁用「（　　　）」全角小括号**（太小写不下）。

## 4. 解答题与答题空间（3 条）

- 解答题下方**不画横线**，只留纯白书写区（用户 9/28 明确）。
- 作答区按**分值**配置（约 130 / 70 / 70 mm 三级）；剩余页高优先给答题区吸收。
- **只有选择 + 解答/说明理由题**留作答区；填空、判断这类一步落答案的题**不留书写区**。

---

## 5. 分页与卡片（3 条）

- **卡片式**：题卡 `break-inside: avoid`，分页不拆题。
- **禁嵌套 KeepTogether**（reportlab 高估块高 → 还有大半页也整段跳页）；大题标题与第一题同卡片，但**不要包两层**。
- **零黑斑**：禁黑底反白、深灰块、渐变黑条；大题标题用上下细实线；提示框边框加深一档（打印后必须可见）。

## 6. 卷面内容红线（防剧透 · 4 条）

| # | 红线 | 判据 |
|:--:|---|---|
| 6.1 | 插图只画**已知条件** | 禁待求量、结论、答案、解题过程、方法提示（"以 O 为原点建系"也算剧透） |
| 6.2 | 采分点提示**只能在答案页/详解页** | 作答卷出现即违规 |
| 6.3 | 识别信号印卷首，只写"看到什么形态 → 哪个题型" | **换到同母题另一道题上仍成立 = 合法；不成立 = 剧透** |
| 6.4 | **含公式的内容禁用表格** | 表格固定格线 vs 动态公式高度 → 实测分数骑线；参考答案一律段落式 |

> 6.1 的机械自查：遍历图内全部文字，命中 `答案/故/所以/因此/结论/最小/最大/最值/轨迹/垂直` 即判违规。

## 7. 密度与体积（v4.19 口径 · 必须按分值归一）

| 指标 | 目标 | 算法 |
|---|---|---|
| 页数 | **≤ 满分 ÷ 20** | 即 **≥20 分/页**；50 分卷 ≤2.5 页（末页不超半满） |
| 题密度 | **≥5 题/页** | 题数 ÷ 页数 |
| 单卷体积 | **≤500KB**（唯一口径） | 超限先查是否误嵌整套字体；原"2MB / 1.5MB"两套口径作废 |
| 正文字号 | **下限 10.5pt** | 禁止靠删题或缩字号达标 |

> **横评两版时必须按"分/页"归一后再比**。反例：15 题/92 分/3 页（30.7 分/页）与 9 题/50 分/2 页（25 分/页）——直接比题数会得出错误结论（页数少只因总分低）。

**已落地手段**：去掉解答题强制分页、行距 1.9→1.75、题距 4pt→3pt、作答区按分值配置。

## 8. 限时（v4.19 公式 · 禁手写）

```
限时(分钟) = 满分 ÷ 1.25   （1.25 分/分钟 = 春考 150 分 / 120 分钟）
容差 ±10%（1.125–1.375 分/分钟）；越界即出卷脚本报错
```

- A 卷 50 分 → **40′**；B 卷 25 分 → **20′**；约 100 分的仿真卷 → **80′（只排周末长时段）**。
- 日预算硬上限 **76′** = A 40′ ＋ B 20′ ＋ 订正 10′ ＋ 详解 5′ ＋ 抽检 1′。
- **限时用孩子实测回校**：实测净用时 > 标注限时 × 1.3 → 判"**限时设计错误，记系统账不记孩子账**"。
  - 铁证：某卷 75 分 / 30′（要求 2.5 分/分钟）孩子做了 51′（1.47，贴着考场），却被记"超时 21′"——**错的是口径，不是孩子**。

## 9. 回归检查（R1–R8 · 改引擎后必跑）

| ID | 检查 | 说明 |
|:--:|---|---|
| R1 | 页数基线 | 改引擎后页数漂移立即报警 |
| R2 | 体积 ≤500KB | **只设上限、不比对精确值**（字体子集化非完全确定，比对精确值会假报警） |
| R3 | 无字面 `$` 残留、无 `Math input error` | 公式渲染失败的典型症状 |
| R4 | HTML 吞字符残留 | 标签未闭合/转义错 |
| R5 | 填空实线条数 | 与题数对得上 |
| R6 | 选项同行坐标判定 | 实际一行几个，与"4/2/1"判据一致 |
| R7 | U+FFFD 缺字 | 编码损坏 |
| R8 | 每页页脚页码（含文件名） | 漏页脚 = 打印后无法归属 |

**R1–R8 之外，本系统另有不可省的三项**（易被新引擎漏掉）：
1. **行首禁则**：`pdftotext -layout` 抓 `^[。，、）)]` 应为 0；
2. **图文几何重叠**：PyMuPDF 逐页比 `get_image_info()` 与 `get_text('dict')` 的 bbox，**排除"包含该图的整行 span"**后应为 0；
3. **字形缺失**：reportlab 遇缺字形会在文本层写 NUL（`\x00`），HTML 链路则表现为回退字体/空框——两路都要查。

---

## 10. 中文禁则（reportlab 不做，HTML 的 `wordWrap` 也做不全）

- **行首禁则字符**：`。，、；：？！）］｝》」』”’…—·〉】`
- **行尾禁则字符**：`（［｛《「『“‘〈【`
- **数字与量词不得断开**：`第 6 题`、`连续 2 次`、`限时 30 分钟` 不能被劈成两行。
  做法：数字与中文之间的普通空格换 `U+00A0`（不换行空格）；公式/标签内不动。
- 实现要点：预排宽度比真实可用宽度**窄一个全角字**（留给标点悬挂）→ 切原子 → 用**与渲染同一字体**量宽 → 贪心填行 → 两遍禁则修正 → 用 `<br/>` 固定行。

## 11. 出卷脚本纪律

1. **只改数据，不改引擎**：新增 Day 复制上一份 `gen_*/data_*`（或 `make_dN.py`），**不要改 `build.py` / `style.css` / `ws.py`**——一改影响所有卷。
2. **看退出码，不看绿字**：`python3 make.py > log 2>&1; echo "exit=$?"`。**绝不用管道**（`| grep 放行` 会吞掉退出码，脚本已报错你却看到上次成功的输出）。
3. **答案数值必须脚本算**：包括验算用的中间值；手写验算＝自己给自己判卷。
4. **AI 明文版随卷**：每份卷子/详解/台阶页配 `*_AI明文.md`（公式还原成 LaTeX），否则外部复核会把"图片位置的空白"误报成"漏印"。
