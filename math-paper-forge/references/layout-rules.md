# 试卷排版规则（数学 · 中文混排）

本文件按需加载。SKILL.md 里是梗概，这里是细则。

## 1. 中文禁则（必须自建，reportlab 不做）

**行首禁则字符**（不得出现在行首）：
`。，、；：？！）］｝》」』”’…—·〉】％‰℃°`

**行尾禁则字符**（不得出现在行尾）：
`（［｛《「『“‘〈【`

**数字与量词不得断开**：`第 6 题`、`连续 2 次` 不能被从数字与量词之间劈开。
做法：数字与中文之间的普通空格换成 `U+00A0`（不换行空格），公式/标签内部不动。

**实现要点（`ws.py` 的 `fit_lines`）**：
1. 预排宽度比真实可用宽度**窄一个全角字** —— 预留的那点正好容纳"标点悬挂"，
   这样既能把行首标点提到上一行末，又保证每行不超真实宽度、**不会被渲染器二次换行打回原形**。
2. 切"原子"→ 用**与渲染同一套字体**的 `stringWidth` 量宽（否则会二次换行）→ 贪心填行
   → 两遍禁则修正 → 用 `<br/>` 固定每一行。
3. **原子粒度**：`$公式$` 整体一个原子；`<标签>` 零宽；数字字母词整体；
   **连续全角下划线（作答横线）合并成一个不可拆原子**；其余单字。

## 2. 字号与行距

| 元素 | 字号 |
|---|---|
| 正文 | ≈12.5pt |
| 大标题 | ≈18pt（试卷主标题 16pt） |
| 题号括号内的（性质·标签） | 比正文**小 2 号**（≈10.5pt） |
| 考点提示（灰色小字） | ≈9pt |
| 行距 | 24pt |

**行内公式必须限高**：`\dfrac` 竖排分式可达 34pt，行距只有 24pt 时必然骑到上下行。
按比例缩到 ≤ 行距 − 3pt。出卷后逐题扫一遍有没有超高公式。

## 3. 作答区（三类题三种做法）

| 题型 | 做法 |
|---|---|
| 填空题 | **只用一条完整横线**（全角下划线 `＿`）。横线**下面不加书写区**，题与题之间不留大块空白。 |
| 选择题 | **只给一条横线**；题干里**不要再印「（　）」**。 |
| 解答题 / 需说明理由题 | 留**纯空白书写区**（`LinedCanvas`，不画横线）。行数：一问 3 行、两步以上 5 行、含说明理由或多小问 4–6 行。 |

**横线长度**（按答案长度留足，但不要一味加长）：

| 答案形态 | 横线单位数 |
|---|---|
| 1–2 字符 | 6 |
| 3–5 字符（分数/根号/正负号） | 8 |
| 含范围或不等式 | 10 |

> 横线太长会被挤到题干下一行。**能接在题干末尾就接上，放不下就整条下移，绝不拦腰断行。**

## 4. 版式

- **选择题选项两个一行**：`A．…　B．…` / `C．…　D．…`。
  不要一行一个（太占地方），也不要四个挤一行（互相粘连——字母后用全角点「．」，
  选项相对题干悬挂缩进约 25pt）。
- **答案另起一页**，独立成页。**禁止**"沿虚线对折覆盖"这类设计 —— 打印即用，无需折叠裁切。
- **解答题整块（题干＋图＋书写区）设为不可拆分**（`KeepTogether`），
  否则书写区会单独溢出，生成一页只有页码的空白页。
- 每个大题标题下加一行灰色小字「考点提示」。
- 题号格式：`1、★★（性质·分组标签）`。

## 5. 数学排版

- **公式用行内图片**：matplotlib mathtext 渲染成**透明 PNG（dpi 400）**，
  在段落里用 `<img>` 内嵌 → 实现分数叠放、根号、上下标与中文混排。
- **mathtext 注意**：
  - `\sqrt` 必须写 `\sqrt{4}`，不加花括号会解析失败；
  - 只用 `\leq` / `\geq`（不支持 `\le` / `\ge`）；
  - 不支持 `\left` / `\right` / `\mathbf` / `\dfrac12` 这类写法；
  - **`\text{}` 里不能放中文**（会缺字）。
- **禁用 Unicode 上下标**（`₀₁₂ₙ⁰⁵⁶⁷⁸⁹`）—— 中文字体常不含这些字形，渲染成方框。
  改用 `<sub>` / `<super>` 标签或普通数字。

## 6. 配图

- 图内**只放几何元素与已知条件**，**严禁结论、解题步骤、公式推导**。
- 图不要太小（限高给够，否则宽高比偏"方"的图会被压窄）。
- **立体图三条几何断言**：直棱柱/直棱锥的侧棱必须竖直；上底面必须整体高于底面；
  底面"深度偏移"必须明显小于侧棱高（否则看着像屋脊）。
- 出图后自检：**文字互不重叠 / 不压线不越框 / 无泄题词 / 不小于尺寸下限**。
  自检本身要用"已知会违规的输入"验一次，确认它真会报警。

## 7. 出稿后机器自检（不靠肉眼）

1. **缺字筛查**：用字体 cmap 扫 PDF 全文，确认无缺字形。
2. **行首标点扫描**：应为 0。**注意假阳性** —— 行内公式图会让 PDF 文本层断行，
   文本层看到的"行首标点"未必是视觉行首，需结合几何检查（比对文字与图片的包围盒）。
3. **空白页检测**：>2 页时逐页看有没有只有页码的空页。
4. **横线断行检测**：扫 `＿+\n＿+`，应为 0。
