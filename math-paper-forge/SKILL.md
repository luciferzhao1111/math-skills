# 数学试卷锻造（math-paper-forge）

**一句话**：题目 → 可打印 PDF（排版过关）→ 硬红线校验（质量过关）→ 放行或拒绝。

这个技能的价值不在"能生成 PDF"（谁都能），而在**两件被反复踩出来的事**：
① **中文＋公式混排的排版脏活**（标点不落行首、公式不骑上下行、作答区有讲究）；
② **出卷质量用"退出码"裁决**，而不是靠肉眼看一遍说"应该没问题"。

---

## 一、什么时候用 / 不用

| 用户说 | 走这条 |
|---|---|
| "出一份练习卷/测验卷/单元测试" | 完整流水线（下方 §三） |
| "把这些题做成 PDF 打印" | 从 §三 第 3 步开始 |
| "帮我看看这份卷子有没有问题 / 校对一下" | 只跑 §四 的闸门 |
| "这道题怎么做 / 讲一下这道题" | **不用本技能**（用讲解类技能） |
| "批改孩子的卷子 / 判分" | **不用本技能**（用判卷类技能） |

## 二、先记住五条工程铁律（血泪换来的）

1. **看退出码，不看输出里的"绿字"。**
   出卷脚本必须 `python3 make_paper.py > log 2>&1; echo "exit=$?"`。
   **绝不能用 `python3 make_paper.py | grep 放行`** —— 管道会吞掉退出码，
   脚本早已报错、你却看到上一次成功的输出，以为成功了。（实测栽过：PDF 一直是旧的，白改好几轮。）

2. **中文排版必须自建禁则，reportlab 不做。**
   `wordWrap='CJK'` 也不做：`，。、）` 会落到行首，`数字` 与 `量词` 会被劈开。
   本技能自带 `scripts/ws.py`（切原子 → 按同字体量宽 → 贪心填行 → 两遍禁则修正 → `\n` 固定行）。

3. **公式一律写成 r-string，且只写单反斜杠。**
   普通字符串里 `\f`（`\frac`）会被当换页符、`\t`（`\times`）当制表符吃掉，
   落盘后表现为 `SyntaxWarning: invalid escape sequence`。

4. **渲染层按环境选型，内容层与判定层必须同源。**
   有 Chrome / 有本地字体时用 `typeset/`（HTML→MathJax→Chrome→PyMuPDF，公式基线天然对齐、体积可压到 400KB）；
   没有这些依赖的环境用 `scripts/ws.py`（reportlab+matplotlib）**等效链路**。
   **绝不要写"某引擎唯一正本、其他作废"** —— 那会让没有该环境的一方**无 PDF 可出**。
   可换的是渲染器；**不可换的是题目数据、分值/限时常量、版式纪律（§8.0①–⑭）与判定口径（G/R 系列）**。
   详见 [`references/typeset-rules-v419.md`](references/typeset-rules-v419.md) §0。

5. **日期一律用代码核星期，不凭印象。** `datetime.date.fromisoformat("2026-10-25").weekday()`（0=周一）。
   凭印象写过一次，整张排期表错一天 —— 这类错**不报错、只慢慢歪**。

## 三、完整流水线

### 第 1 步：确认题目规格（SPEC）

每道题至少要有：题号、题型（填空/选择/解答）、分值、**分组标签**（如母题号 `M-xxx-01`）、
来源锚点、**变换算子**、性质（新/复现/保温）、题干、参考答案。

> **为什么要有"分组标签 + 算子"**：查重、间隔、覆盖统计全靠这两个字段。
> 没有它们，闸门无法工作（见 §四 G5）。

**每题的元数据（缺一项就不许进卷）**：

| 字段 | 说明 |
|---|---|
| 分组标签 | 母题号，如 `M-立几解-02` |
| 性质 | 首覆 / 复现 / 保温 —— **必须与事实一致**（首次进卷不许标"复现"；曾把首次使用的母题标成复现，属"把不存在的事写成事实"） |
| 分值 / 难度档 | 分值；难度档 ★1–★4（**题目侧**的变式档，不是学生能力档） |
| 锚 | 真题出处（年·卷·题）；**只取原卷某一问时必须注明"只取第 N 问"**，否则按虚标处理 |
| 变换算子 | 每题必须有（G5 硬检） |
| **一题多考点必须全挂** | 复合题（如分段函数+对数）**双挂母题**，单挂＝取锚过窄 |

**结构必须显式声明并校验**：每份卷先写清「题型×题数×分值 = 满分」这一行，
再由脚本校验合计。**数值由项目注入，技能只负责"必须声明且必须相等"**。
（实测：演练卷选择题写成 4×5=20，总分变 152 —— 两分钟能查出来的错，漏了三轮。）

**换壳空间（载体）分两级，别混**：

```
格   = 教材级分类（如"锥·多面体"）         → 用于统计"换壳空间走过了多少"
形态 = 解题动作分类（如"三棱锥(侧棱⊥底)"） → 用于选题（决定要不要作高/补形）
解法 = 几何法 / 向量法                     → 第三栏，不是载体
```
把「解法」当载体、或把「n 棱锥」按底面边数拆成多个载体，都会让覆盖率算错。

### 第 2 步：SG6 —— 答案数值必须由脚本算，禁止手写

所有答案里的数、区间、最值，都用 `sympy` 现算一遍，并把结果打印出来核对。
**手写验算 = 自己给自己判卷。**

> 实测教训：一道概率题参考答案写「剩 4 个球、概率 1/2」，正确是「剩 5 个、3/5」——
> 根因是连"验算变量" `V['A7']=(4,2)` 都是手写的错值。**错的验算会掩盖错答案。**

### 第 2.5 步：难度特征禁用主观估时

若用回归/BT 之类的模型估难度，**特征里不许放"命题人估计用时"** —— 那是按难度直觉标的，
等于**用主观量解释主观量**（循环论证）。实测：放进去后权重会整个塌缩到它一个，其余特征全变 0 权。
可用的是**可数**特征：推理步数、子技能数、是否含证明、是否含"是否存在"、含参个数、是否需表征转换。

### 第 3 步：排版（用 `scripts/ws.py`）

- **正文约 12.5pt，标题约 18pt**；大字比小字重要（这是给孩子看的）。
- **公式用行内图片**：`matplotlib` mathtext 渲染成透明 PNG（dpi 400），在报告里用 `<img>` 内嵌，
  实现分数叠放/根号/上下标与中文混排。
- **行内公式必须限高**：`\dfrac` 竖排分式可达 34pt，而行距常只有 20–24pt，必然骑到上下行。
  按比例缩到 ≤ 行距 − 3pt。

**作答区规则（三条，都是被用户反复纠正出来的）：**

| 题型 | 作答区 |
|---|---|
| 填空题 | **只用一条完整横线**（全角下划线）。横线**下面不要再加书写区**。 |
| 选择题 | **只给一条横线**。**不要再在题干里印「（　）」** —— 括号+横线两份并存是错的。 |
| 解答题 | 留**纯空白书写区**（3–6 行，按小问数定）。**不要画横格线。** |

**版式规则：**

- **选择题选项两个一行**（`A．… B．…` / `C．… D．…`）。不要一行一个（太占地方），也不要四个挤一行（互相粘连）。
- **作答横线是"不可拆原子"**：能接在题干末尾就接上，放不下就**整条**移到下一行；
  **绝不能在横线中间断行**（出现「＿＿＿＿\n＿＿」半截线）。
- **填空题横线长度按答案留足**：1–2 字符给 6 个单位；3–5 字符（分数/根号）给 8；
  含范围或不等式给 10。**但不要一味加长** —— 横线太长会被挤到下一行，反而难看。
- **参考答案必须另起一页独立成页**。**严禁**"沿虚线对折覆盖"这类设计 —— 要做到打印即用、无需折叠裁切。
- **标题下方加一行灰色小字「考点提示」**。
- 题号统一格式：`1、★★（性质·分组标签）` —— 括号内字号比正文小 2 号。

### 第 4 步：配图（如需）

平面几何、立体几何、函数图像、解析几何都可配。**三条硬规矩：**

1. **图内严禁出现答案**：不得有结论、解题步骤、公式推导，只允许几何元素与**已知条件**标注。
   （实测翻车：解三角形题的配图里印了「$A=\frac{\pi}{3}$ 或 $\frac{2\pi}{3}$」，而题目问的就是"求 $A$"。）
2. **图不能太小**：限高大一点，否则宽高比偏"方"的图会被压窄到看不清。
3. **立体图要过几何断言**：直棱柱/直棱锥的侧棱必须画竖直；上底面必须整体高于底面；
   底面"深度偏移"必须明显小于侧棱高（否则看着像屋脊，不是棱柱）。

**立体图：被遮挡的后棱必须画虚线**（`stroke-dasharray`）。实线画全＝看不出前后关系，
孩子会把后棱当成前面的边，整道题的图就读反了。

**出图后必须跑自检**：文字互不重叠、文字不压线不越框、**图内无泄题词**、图不小于尺寸下限。
自检本身也要验 —— 用一句已知会违规的文字，确认它真的报警（否则就是永远绿灯的假自检）。

### 第 5 步：出 PDF

- **试卷与答案分文件**（`xx.pdf` / `xx_答案.pdf`）。
- 解答题整块（题干 + 图 + 书写区）用 `KeepTogether`，**否则书写区会单独溢出，生成一页只有页码的空白页**。

### 第 6 步：过闸门（见 §四）——**不过就不发**

## 四、出卷闸门（六条校验）

`scripts/gate_check.py` 从卷子的结构化数据（`papers/*.json`）读题，跑六条校验，
**退出码 0 = 放行、1 = 有硬红线**。调用方据此拒绝出卷。

| 编号 | 校验 | 判据 |
|---|---|---|
| **G0** | 卷号登记 | 卷号不在登记表中 → **硬红线**（不得静默放行；实测过"无数据就跳过"导致闸门形同虚设） |
| **G1** | 原题查重 | 本卷题干 × 历史各卷题干，**跨分组标签也比**：≥0.80 硬红线、≥0.70 警告 |
| **G2** | 复现间隔 | 同一分组标签距上次出现 **< 2 卷** → 硬红线（**按卷序算，不按日历日**） |
| **G3** | 同卷重号 | 本卷内同一分组标签 ≥2 题 → 警告 |
| **G4** | 同日相交 | 同一天的另一份卷，考点集合与本卷相交 → 硬红线 |
| **G5** | 算子登记 | 每题缺"变换算子" → 硬红线 |
| **G6** | 答案数值 | 与脚本独立算值比对（见 §三 第 2 步） |
| **G7** | 结构与分值 | 声明行「题型×题数×分值」合计 ≠ 满分 → **硬红线**（见 §三 第 1 步） |
| **G8** | 新颖度预算 | 单题 `骨架首次 + 深变式(★≥3)` 超过该题位预算 → **硬红线**；单卷深变式题数 ≤30% |

**G7/G8 之外的六条补充判据（都来自真实事故）**：

| # | 判据 | 说明 |
|:--:|---|---|
| 1 | **三元组查重** | 同分组标签 ＋ 同指数/系数 ＋ 同答案 ⇒ 判撞车。**换字母不算换题** —— 只比解析式会漏（短式还会被跳过） |
| 2 | **5-gram 原文重合率 <15%** | 与真题原文比，防"原文进题面"。与 G1（题干相似度）互补：G1 比结构，5-gram 比字串 |
| 3 | **首覆/复现标注与事实一致** | 标"复现"的必须真的在更早的卷出现过；标"首覆"的必须真的没出现过 |
| 4 | **填空难度必须跨 ≥2 档** | 整卷全 lv1 ＝ 难度扁平，看不出真实水平 |
| 5 | **卷面 PDF 文本层** `答案：`/`正解`/`解析` **必须 0 处** | 脚本扫，不靠肉眼；题目版件出现任一即硬红线 |
| 6 | **改判据必须造坏样本** | 新增/修改一条校验后，造一个已知违规样本，确认它**真的叫**（退出码 1），否则就是永远绿灯的摆设 |

**几个必须知道的细节：**

- **G1 必须跨分组标签比。** 实测翻车：两道题是**同一个几何体、同一组已知条件**（只换小问），
  相似度 0.84，但一个挂 `M-…-02`、一个挂 `M-…-01` —— 早期版本"只比同组"，直接跳过、放行。
  **换个标签就能"换皮"过关，是闸门最大的漏洞。**
- **改 G1 前先验误报**：全库跑一遍，看"跨组 ≥0.80"会多出多少对，逐对确认是不是真重复。
  实测 172 题只多 2 对且都是真重复 → 才敢改。**否则宁可保守。**
- **G2 的间隔按"卷序"算，不按日历。** 学生一天做三份卷是常事；
  若按日历算，同日就都是"0 天间隔"，全部误报。
- **通用题干骨架是噪声**：像「在 △ABC 中，角 A、B、C 的对边分别为 a、b、c」这种标准表述，
  不同题之间相似度天然偏高（实测 0.72），**不要为此改题**。

## 五、发布前自检清单

- [ ] 出卷命令**看了退出码**（`exit=0`）
- [ ] 闸门 **0 硬红线**
- [ ] PDF 全文**缺字筛查**（用字体 cmap 扫一遍，确认无方框/缺字）
- [ ] **禁用 Unicode 上下标**（`₁₂ₙ⁰⁵⁶` 等）—— 中文字体常不含这些字形，渲染成方框；
      改用 `<sub>` / `<super>` 或普通数字
- [ ] 行首标点扫描为 0（**注意**：公式图会让 PDF 文本层断行，这个扫描会有假阳性，需结合几何检查）
- [ ] 每页都看过一眼（**空页、半截横线、图形压字**是三大高频事故）
- [ ] **防剧透**：卷面插图内无「答案/故/所以/结论/最值/轨迹」等结论词；采分点提示没印在作答卷
- [ ] **体积 ≤500KB**（唯一口径；超限先查是否误嵌整套字体）
- [ ] **密度按分值归一**：页数 ≤ 满分÷20（≥20 分/页）且 ≥5 题/页
- [ ] **限时 = 满分 ÷ 1.25**（考场配速 1.25 分/分钟，容差 ±10%；禁手写）
- [ ] **结构声明行存在**，且 题型×题数×分值 合计 = 满分（G7）
- [ ] **首覆/复现 标注逐题核过**，与历史卷事实一致
- [ ] **三元组查重跑过**（不只跑 G1 相似度）
- [ ] **日期用代码核过星期**
- [ ] **改了任何判据 → 造坏样本验过它会叫**

### 1.4.0（2026-11-05）

按"规则 → skill 逐条对照"补 16 条：

- 新增 **G7 结构与分值**、**G8 新颖度预算**两条闸门
- 闸门补充六条：**三元组查重**（换字母不算换题）、**5-gram <15%**、**首覆/复现标注须与事实一致**、
  **填空难度跨 ≥2 档**、**卷面 PDF 文本层三词 0 处**、**改判据必造坏样本**
- 第 1 步强化：题头元数据六项（含"一题多考点双挂"、"只取某问须注明"）、**结构必须显式声明并校验**
- 新增 **载体分「格/形态/解法」三级**（把解法当载体会算错覆盖率）
- 新增 **第 2.5 步：难度特征禁用主观估时**（循环论证）
- 立体图补 **被遮挡后棱用虚线**
- 铁律加第 5 条：**日期一律用代码核星期**

### 1.2.0（2026-10-19）

- **行内分式禁 `\dfrac`**：`ws.P()` 内统一降级为 `\frac`（竖排分式 34pt vs 行距 24pt，会骑线或被 `max_h` 压小）。独立大公式走 `mimg`，不受影响。
- **公式/图 dpi 400 → 600**：`ws.DPI = 600`；出卷后核体积 ≤500KB（答案 PDF 可回降到 400 控体积）。
- **体积分档**：练习卷/答案 ≤500KB；**详解/订正页不设 500KB 线，≤1.5MB**（详解含大量公式图）。
