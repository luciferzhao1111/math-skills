# 示例数据（可直接跑）

这个目录里的数据是**虚构的**，只为让你 clone 下来就能把闸门跑起来。两条路径都覆盖了：

## ① `minimal/` —— 一套合规的卷子（闸门应放行）

三份卷、共 10 题，考点按间隔规则错开，应当 **0 硬红线**。

```bash
cd math-paper-forge
MATH_SKILLS_WS=examples/minimal python3 scripts/gate_check.py --all > /tmp/g.log 2>&1; echo "exit=$?"
# 期望：exit=0
```

## ② `violation/` —— 一道"换了标签的换皮题"（闸门应拦下）

`B2` 的题和 `B1` 的题是**同一道利润应用题、只有数字不同**，而且刻意挂了**不同的标签**
（`M-甲-01` vs `M-乙-01`）—— 这正是闸门最该抓、也最容易漏掉的作弊方式。

> ⚠️ **已知局限（重要，别踩）**：查重靠的是**题干文本**。
> 题干太短时（例如「解方程 $2x+7=15$」），`+`、`=` 会被归一化剥掉、只剩数字差异，
> 相似度可能掉到 0.67 以下而**漏过 0.80 红线**。
> 实测：把上面两条换成短方程题，相似度只有 **0.67 → 放行（漏报）**；
> 换成带情境的长题干，相似度 **0.95 → 拦下**。
> **结论**：出卷时题干要写完整（带情境/条件），别用光秃秃的短式子 —— 既为孩子好读，也让查重有效。

```bash
MATH_SKILLS_WS=examples/violation python3 scripts/gate_check.py --all > /tmp/g2.log 2>&1; echo "exit=$?"
# 期望：exit=1，且打印 "G1 高度疑似原题 … ← **跨母题**"
```

> 若第二条只打印一行 `无数据`，说明 `MATH_SKILLS_WS` 没指对目录 ——
> **`exit=0` 就是"闸门被跳过"，而不是"卷子合格"**（见 SKILL.md §四 G0）。

## 数据格式

`papers/<卷号>.json`：

```json
{
  "date": "2025-03-01",
  "items": {
    "1": {
      "m": "M-代数-01",        // 分组标签（母题号）。查重/间隔/覆盖统计全靠它
      "tag": "一元二次方程·因式分解",  // 人看的考点名
      "op": "换数字",           // 变换算子（G5 硬校验：不许缺）
      "ans": "$x=2$ 或 $x=3$",  // 参考答案（G6 用脚本独立算值核对）
      "stem": "解方程 $x^{2}-5x+6=0$。"   // 题干，公式写 LaTeX
    }
  }
}
```

- 卷号里的数字会被当作**卷序号**（间隔判定按卷序、不按日历，见 SKILL.md §四）。
- `stem` 里的公式用 LaTeX（`$...$`）—— **查重要比公式里的数值**，所以给结构化 json 而不是 PDF。
- 一个 `m` 只对应一个题型；同一真题的不同小问若考点不同，**拆成不同 m**。
