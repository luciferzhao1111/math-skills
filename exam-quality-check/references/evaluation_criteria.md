# 五维评分细则（10 分制）

每维 1–10 分（可含 0.5）。评分必须附 `evidence`，能指到**具体题号**。评分前必读本文件。

---

## 1. 内容效度（权重 25%）
- **10**：所有考点命中该学段高频考点；答案逐题正确；一题一点；无超纲。
- **7–9**：考点基本命中，个别冷门但不超纲；答案全对。
- **4–6**：有 1–2 处超纲或答案存疑；或一题考两点。
- **1–3**：多处超纲 / 答案错；考点偏离该学段考纲。
- 扣分：答案与题干不符 −1/题；超纲 −1/题；一题多考 −0.5/题。

## 2. 结构效度（权重 20%）
- **10**：题型配比合现行结构；选项长度对称、干扰项有效；正确选项分布均衡（标准差 ≤7）。
- **7–9**：小瑕疵（个别选项偏长、分布略偏）。
- **4–6**：正确选项分布失衡，或干扰项明显不成立。
- **1–3**：结构混乱 / 选项设计失效。
- 扣分：正确选项分布标准差 >7 −1；某选项最长且占比 >45% −1；干扰项明显不成立 −0.5/题。

## 3. 难度控制（权重 20%）
- **10**：每题标难度档；梯度清晰（易→难）；与**目标分**匹配；选做/压轴预标"可跳"。
- **7–9**：档位基本全，梯度尚可。
- **4–6**：缺档位标注，或梯度倒挂。
- **1–3**：难度与目标严重错配。
- 扣分：未标难度档 −1/题；梯度倒挂 −1；有压轴却无"可跳"预标 −1。

## 4. 区分度潜力（权重 15%）
- **10**：能区分中上/中下；有适量中档题；对**中下水平学生**有"够得着"的台阶。
- **7–9**：区分意图基本明确。
- **4–6**：题目偏两头（全送分或全难题）。
- **1–3**：无区分设计。
- 扣分：全送分或全难题 −2；无中档过渡 −1。

## 5. 规范性（权重 20%）
- **10**：考点编号 / 难度档 / 满分 / 变式登记表齐全；变换算子标注规范；真数学排版；无方框、无 `$` 源码；答案独立成页；无"对折"；无错别字。
- **7–9**：小瑕疵（个别标注缺、轻微排版问题）。
- **4–6**：缺关键标注（如无考点编号或登记表）。
- **1–3**：多处规范缺陷。
- 扣分：缺登记表 −2；无编号 −1/题（最多 −3）；含方框 / `$` 源码 −1/处；答案未独立成页 −2；含"对折" −2；错别字 −0.5/处。

---

## 综合分

```
加权平均 = Σ(维度分 × 权重)
综合分   = min(加权平均, 最低维度分 + 2)      # 短板机制
```

**判定**：

| 综合分 | 结论 |
|---|---|
| ≥ 8.5 | **Go**（优，可直接下发） |
| 7.0 – 8.4 | 基本可用（小改后下发） |
| < 7.0 | **No-Go**（回炉重做） |
