# 数学试卷 · 命题质量质检（exam-quality-check）

## 为什么需要它

出卷容易、出好卷难。学生时间有限 —— 练一份低质卷，等于白费一晚。
本技能把"这套卷子有点虚"翻译成质检单上的**硬话**，给出**可执行的修改清单**，并判定 **Go / No-Go**。

核心机制是**五维评分 + 短板机制**：不允许某一维只有 3 分，却被其他维度平均成 8 分。

## 输入

- 卷面 **.md**（首选，便于核对考点编号 / 难度档 / 变式登记表）
  或 **PDF**（用 PyMuPDF 抽文本层；注意"混合型" PDF —— 文字在文本层、公式是位图）
- 可选：对应的考点锚点表 / 真题锚点（用于校验"关联考点"是否成立）

## 五维评分（各 1–10 分）

| 维度 | 权重 | 检查点 |
|---|---|---|
| **内容效度** | 25% | 考点是否命中该学段的高频考点；**无超纲**；一题只考一个点；**答案与题干一致（逐题重算）** |
| **结构效度** | 20% | 填空 / 选择 / 解答配比合现行结构；选择题选项长度对称、干扰项"似是而非"；正确选项分布 |
| **难度控制** | 20% | 每题标难度档；与**目标分**匹配；梯度由易到难；选做 / 压轴预标"可跳" |
| **区分度潜力** | 15% | 对**中下水平学生**是否有区分意图；既非纯送分、也非纯难题 |
| **规范性** | 20% | 考点编号 / 难度档 / 满分 / 变式登记表齐全；变换算子标注；真数学排版；无方框、无 `$` 源码；**答案独立成页**、无"对折"设计；无错别字 |

**综合分 = `min(加权平均, 最低维度分 + 2)`** —— 短板机制。

> 评分细则见 `references/evaluation_criteria.md`（**评分前必读**）。

## NEVER（违反即判缺陷并写入报告）

1. **禁止**用纯加权平均作为综合分 —— 必须走短板机制。
2. **答案正确性必须逐题重算** —— 不得只信生成脚本。
   （实测教训：`file_edit` 与脚本都出现过"返回成功却没落地"的静默出错。**独立重算才是证据。**）
3. 填空题答案唯一性由 Agent 判断，**不交给脚本**。
4. 出现排版缺陷（方框、`$` 源码、答案未独立页、残留"对折"）→ 规范性直接扣分。
5. 考点只覆盖 ≤ 2 个高频考点时，**不给"良好"及以上**。
6. 选择题正确选项分布严重失衡必须指出。

## 工作流

1. **取卷**：读 .md；或对 PDF 用 PyMuPDF 抽文本层
2. **提题**：列清单（题号 / 考点 / 编号 / 难度档 / 分值 / 答案）
3. **逐题验算**（NEVER-2）：独立重算每题的答案与关键中间步骤
4. **五维评分**：每维给分 ＋ 一句 `evidence`（必须能指到**具体题号**）
5. **短板合成**：综合分 = min(加权平均, 最低维度 + 2)
6. **出报告**（见下）

## 输出：`质检报告.md`

```
# 试卷质检报告 · <卷名>
结论：Go / No-Go ｜ 综合分 X.X
五维：内容_/结构_/难度_/区分_/规范_   （短板：最低维 X → 综合上限 X+2）
逐维 evidence：…
问题清单：
  P0（阻断下发）：…
  P1（建议改）：…
  P2（可选）：…
```

## 两个示例

- **示例 1（md 卷）**："质检一下这套单元卷" → 读 md，逐题验算；发现正确选项分布失衡 → 结构效度扣分；编号 / 登记表齐全 → 规范性满分；**短板在结构 → 综合分被压**。
- **示例 2（PDF 卷）**："这两套卷哪套命题水平更高" → 分别抽文本层、五维评分，输出对比与 Go/No-Go。

## 与其它环节的关系

- 上游：出卷（绑考点、标难度档、附变式登记表）—— 见 `math-paper-forge`
- **本环：质检 → 不合格则回炉**
- 下游：批改作答 → 更新掌握度 → 调参 —— 见 `math-grader` / `math-mastery-scheduler`

> 质检是**别让学生练低质卷**的那道闸门。
