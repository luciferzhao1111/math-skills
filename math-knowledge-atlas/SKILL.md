# 知识地图（math-knowledge-atlas）

**一句话**：把"这个考点不会，到底该先补什么"从**凭感觉往后翻教材**，变成**在图上追一条链**。

三件事：

1. **存下来** —— 考点之间的关系（前置 / 常同框）写成一份 `atlas.json`。
2. **校验** —— **前置关系不能成环**（人眼看不出，代码一跑就现形）。
3. **用起来** —— 分层看全局、追链补薄弱、出图给人看。

---

## 一、什么时候用 / 不用

| 用户说 | 走这条 |
|---|---|
| "他二次函数老是错，是不是前面哪里没打好？" | `atlas.py path <考点>` 追前置链 |
| "帮我理一下这学期知识点的关系 / 画张知识地图" | 建 `atlas.json` → `mermaid` 出图 |
| "这些考点哪些常一起考？" | `atlas.py cooccur` |
| "从哪开始教 / 先学什么？" | `atlas.py levels` 看拓扑分层（第 1 层是地基） |
| "出卷 / 批改 / 怎么升档" | **不用本技能**（分别用 forge / grader / scheduler） |

---

## 二、数据模型（就三个字段）

```json
{
  "nodes": {
    "K-一元二次方程": {"name": "一元二次方程", "stage": "初中", "anchor": "九年级·一元二次方程"}
  },
  "prereq": {
    "K-一元二次方程": ["K-因式分解", "K-一元一次方程"]
  },
  "cooccur": [
    {"a": "K-二次函数", "b": "K-一元二次方程", "note": "判别式、最值常同框"}
  ]
}
```

- **`nodes`**：考点本身。`id`（自定）＋ 名称 ＋ 学段 ＋ **教材锚点**（哪一章，用来回课本）。
- **`prereq`**：**要学左边，先会右边**。这是地图的骨架。
- **`cooccur`**：**常一起考**的组合（证据来自真题统计，不是猜的）。

> **id 怎么取**：与出卷技能里的"分组标签"（母题号）用**同一套**，
> 这样"考点的关系"和"题的归属"能对上。

## 三、三个用途

### 3.1 校验：把"环"抓出来

**前置关系是偏序，不能成环。** 一旦写出 `A ← B` 又 `B ← A`，
说明你把"依赖"和"相关"搞混了 —— 这会让"该先补什么"永远算不出。

`atlas.py validate` 同时查三种毛病：

| 毛病 | 什么意思 | 怎么改 |
|---|---|---|
| **环** | A 是 B 的前置，B 又是 A 的前置 | 拆成"相关"（放 `cooccur`），别当前置 |
| **悬空前置** | 前置节点根本不在 `nodes` 里 | 补上该节点，或删掉这条前置 |
| **孤立点** | 与任何考点都没有关系 | 要么补关系，要么确实是独立模块（可接受） |

### 3.2 分层：看全局的先修顺序

`atlas.py levels` 做**拓扑分层**：第 1 层 = 无前置（地基），逐层往上。
教学/复习顺序**从第 1 层往上**走，不要跳层。

### 3.3 追链：从薄弱点往回补

`atlas.py path <目标>` 输出**前置闭包链**（要学目标，按顺序先把这些补齐）。

> 这是本技能**最实用的一个**：学生"二次函数总错"，链上一追可能发现
> **根子在一元二次方程的因式分解** —— 那就别在二次函数上耗，回去补前面。

---

## 四、三个必须注意的点

1. **"前置"与"相关"是两回事。**
   前置 = **不会它就到不了**（必要）；相关 = **常一起出现**（不必要）。
   把相关当前置，就会造出环。**混了就往 `cooccur` 里放。**

2. **别把地图建成"教材目录"。**
   地图的价值在**跨章节的依赖**（如"导数 ↔ 函数单调性"），
   照抄目录做出来的东西没有信息量。

3. **节点粒度要一致。**
   不要一半是"整个模块"（如"立体几何"）、一半是"单个技巧"（如"韦达定理"）。
   **要么都是模块，要么都拆到技巧。**

## 五、脚本

```bash
python3 scripts/atlas.py atlas.json validate          # 校验（环/悬空/孤立）
python3 scripts/atlas.py atlas.json levels            # 拓扑分层
python3 scripts/atlas.py atlas.json path K-二次函数    # 追前置链
python3 scripts/atlas.py atlas.json mermaid           # 输出 mermaid 图
python3 scripts/atlas.py atlas.json cooccur           # 常同框组合
python3 scripts/atlas.py selftest                     # 内置自检（7 项）
```

**mermaid 输出直接贴进 GitHub README 或 Issue 就能渲染成图**，不用额外画图工具。

> 自检里专门验证了**"环形图必须能检出环"** —— 用一个已知会成环的例子跑，
> 确认它真的报警。**否则就是永远绿灯的假自检。**
