# 数学判卷与详解（math-grader）

**一句话**：学生作答 → ① **辨错确认单**（先给家长核对）→ ② **详解 PDF**（学生版 / 系统版）。

这个技能的价值不在"能写解析"（谁都能写），而在**两件被反复踩出来的事**：

① **观测不可信时，宁可不记。** AI 读手写卷面会错 —— 而且**两次读法一致也可能是错的**。
   所以流程上强制一道闸：**先让家长核对事实，再写错因**。
② **错因必须能被机器/人一致地判定。** 只许两层口径、只许引用卷面原句，
   不许出现"粗心""审题不清"这类自由发挥。

---

## 一、什么时候用 / 不用

| 用户说 | 走这条 |
|---|---|
| "批改这份卷子 / 判分" | 完整流水线（§三） |
| "这道题他错在哪 / 出个错题详解" | 从 §三 第 1 步开始 |
| "帮我把错题整理成 PDF 打印" | 直接跑 `scripts/make_detail.py`（§七） |
| "从零出一份练习卷" | **不用本技能**（用出卷技能 `math-paper-forge`） |
| "这道题怎么做"（没有学生作答） | **不用本技能**（用讲解类技能） |

## 二、先记住四条铁律（血泪换来的）

1. **观测不可信时，宁可不记。**
   同一处**两次读法冲突**、卷面有**涂改/修正带**、家长说的与读图**不一致** —— 三者任一，
   **标 ⚠️ 回问家长**，并**冻结该题的全部计算**（不判对错、不记错因、不更新统计数据）。
   **判决权交家长，AI 只负责说"我看到的"。**

2. **错因只能用两层口径**（§四），且**必须引用卷面上的那一句 / 那一步（原文摘录）**。
   **禁止**写通用模板式错因，**禁止**写他没犯的错。写不出依据 → 标"待人工确认"，宁可空着。

3. **判 ✓ 也要能指到笔迹。** 不只是判 ✗ 要引原句 —— **判 ✓ 必须能在卷面上指出对应的那行字**。
   指不出来 → 说明你看的是"送审册/答案键"，不是学生的卷子。
   （实测事故：把送审册上的答案当学生作答，虚增 11 分。）
   **凡涉及"对/错分界"的读数（分数分母、是否涂改、符号正负），即使两次读法一致也要交家长过目** ——
   两次一致地读错发生过不止一次。AI 只报"我看到的"，不给定论。

4. **详解第一屏 = 错题总览卡。** 实测孩子看详解 <5 分钟、**第 1 页之后基本不看** ——
   把核心放第 2 页 = 没传达。所以**第 1 页必须让"只看这一页"也拿走 80% 价值**（§五）。

## 三、流水线（不可跳步）

### 第 −1 步：列「应交 / 已交 / 缺交」三栏

本轮应交的全部件（卷面、订正页、单练、补交件）逐件列状态。**缺交必须当轮报警，不许写"无"**。
（实测：漏掉两份单练还写"无"，导致连续两轮无人发现孩子没做。）

### 第 0 步：读卷（**只作初稿，不作证据**）

逐题记下两样：**学生答案** ＋ **卷面上可辨认的步骤**（原文摘抄）。
读图得到的结论一律标为"初稿"。

### 第 1 步：出《辨错确认单》（**这一步是硬门槛**）

**先不要写详解。** 先写一张确认单发家长，每题三栏：

| 题 | AI 读到的答案 / 步骤 | AI 判定的错点（含"这一步凭什么"） | ⚠️ 不确定处 |
|----|------|------|------|
| 示例 | 填 5/2，步骤残缺 | 疑似"令 x=y=2 直代"当最值 | 5/2 是否由此而来？ |

> **为什么必须先出这张单**：实测事故 —— 孩子看完详解说
> "虽然我做错了，但你说我**怎么做错的完全不在点子上**"。
> 根因：详解是**按模板套**的，不是**按他实际的错误步骤**写的。**靶子错了，写十页也是背道而驰。**

### 第 2 步：家长确认

- **家长只有"确认权"，没有"解释权"**：只提供**事实**（照片 / 卷面 / 用时 / 是否涂改 / **是否提示过**），
  **不给解法、不给答案、不讲解**。
  → 一旦家长讲了方法，这题就**不再是"独立完成"**，其证据全部失真。**若已讲，在确认单里标"已提示"。**
- 任何"⚠️ 不确定处"**未确认前，不得写进错因**。

### 第 3 步：写详解（第一屏 + 详版）

- **第 1 页**：错题总览卡（每卡固定 6 项）。**只读这一页也能拿走 80% 价值。**
- **第 2 页起**：选读详版（他真想弄懂时翻的字典）。
- 完全不会 / 步骤残缺的题：**必须配图**（概念图 + 分步图 + 错解对照图）。
- 卡在代数推导的题：除图外，再给一座"直觉桥"—— **生活/游戏类比 + 固定动作口诀**。

### 第 4 步：冻结与同源

- 遇"待人工确认" → **冻结该题全部计算**（不升档、不降档、不记错因、不改统计）；
  确认完成后再整体重算。**待人工确认 ≠ 失败。**
- **三处同源**：同一题在**详解 / 台账 / 看板**里的错因必须**逐字一致**，改一处必须同步另两处。

### 第 5 步：结论冲突时必须定版

同一批批改里若出现**前后两次结论冲突**（如重批推翻了初判），必须显式写一句「**最终版＝X，推翻的是 Y，原因 Z**」，
并检查**已落账的记录**是按哪一版记的：
- 按最终版记的 → 在记录里注明，不必重记；
- 按被推翻那版记的 → **不许直接改**（倒序补录会写坏卡），给该批记录标 `invalidated: true`，
  并在到期清单里排除，等下一次真实接触重记。
（实测：同一份辨错单里「据此记了 11 条账」与「已按真实判分落账、无需重记」并存 —— 两句话必须只能有一句是真的。）

## 三·五、评分口径（先定口径，再谈错因）

| 题型 | 口径 |
|---|---|
| 填空 / 选择 | **全对满分，有错 0 分**（不给步骤分） |
| 解答 | **按过程步占分**；**只写答案 ≠ 满分** |
| 答案对但过程为零 | 记「**结果正确 · 思路错误**」，**不得**记成"正确" |
| **"不会" ≠ "做错"** | 整题空白/只写一个符号 = **不会**，走单练；不占靶向坑、不当 Again 记 |
| **选择题：选项即诊断** | 若卷子给了每个干扰项的 `distractor_tag`（错误来源），**选错时错因 = 该选项的 tag**，不用猜。选中的若是"无效选项"（明显错误项），按概念混淆处理并回课本 |

> 「不会」和「做错」混在一起，会让调度把"没学过"当成"学过但错"，从而**反复出同一道不会的题**。

## 四、错因：两层口径（判定的唯一标尺）

**第一层 `primary`（三值、互斥）** —— 判定的**两步不许合并成一句话**：

| 错因 | 判定标准 |
|---|---|
| **计算失误** | 思路方法都对，只是算错 |
| **概念混淆** | 知识点本身没懂（公式记错、定义不清、条件用错） |
| **思路卡壳** | 知道知识点，但不知从何下手 |

**第二步**再独立问一句"那个例行动作做了没有？" → 记 `modifier`（可缺省）：

**第二层 `error_modifier`（动作缺失，词表封顶 5 个，禁止扩张）**：
`习惯性漏步` ｜ `边界遗漏` ｜ `定义域遗漏` ｜ `未做回代` ｜ `分类不完整`

- **两层相加，不是二选一**：`概念混淆 ＋ 分类不完整` 可以同时成立。
- **"能说明" ≠ "能调用"**：事后能解释，不证明当时能独立调用。
  **"能说明但调不出来" 归「概念混淆 / 思路卡壳」，不归「习惯性」。**
- **禁止**另立新根因："粗心"不是错因、是**动作缺失**；"审题不清"要归入概念混淆/思路卡壳
  （可加括号限定词，如 `概念混淆（审题：恰一人/至少一人）`）。
- 策略类问题（如"该跳的题没跳"）**不记错因**，另记 `策略标签`，以免污染错因统计。

### 四.2　学生侧五档 ↔ 系统侧两层（映射表）

订正页/自评表上给孩子勾的选项要**口语化**（他好学）；台账/看板用的字段要**统一**（机器好算）。
两者之间用这张表转换，**不要为了迁就任何一边去改另一边**：

| 孩子勾的 | → `primary` | → `modifier` | → 处置 |
|---|---|---|---|
| ① 没看出考什么 | 概念混淆 | — | 回课本 + 概念变式 |
| ② 看出但不知从哪下手 | 思路卡壳 | — | 拆成 2–3 级台阶 |
| ③ 知道思路但写不出式子 | 思路卡壳**（表征）** | — | 拆台阶 ＋ **先做一次表征转换**（把文字条件翻成坐标/式子） |
| ④ 会做但算错 | 计算失误 | — | 限时计算专项 |
| ⑤ 会做但没写完/没检查 | 计算失误 或 思路卡壳（看错在哪一步） | 习惯性漏步 / 未做回代 | 流程检查单 |

> ③ 用的是**已允许的括号限定词**（同 `概念混淆（审题：恰/至少）`），**不是新根因** —— 所以这张表不改口径，只补接口。
> **孩子没勾时**：不许替他猜一个填上，标"待确认"。

> 详细判据、边界情形与历史事故见 [`references/grader-rules.md`](references/grader-rules.md)。

## 五、详解排版规则

| # | 规则 | 要点 |
|:--:|---|---|
| ① | **第一屏原则** | 第 1 页 = 错题总览页。每卡固定 6 项：`你写的` → `正确方法` → **`★ 错在哪`（红）** → **`✔ 怎么改`（绿，口诀一句话）** → `本题本质` → `下一步动作`。末尾一行动作指令：「**现在合上答案，把每道题卡住的那一步各重做一遍**」 |
| ② | **可跳过分层** | 正文标 **【必看】**（图＋结论）／**【细读】**（步骤）／**【可跳】**（灰色：历史错误、元认知）。**颜色即优先级**，让他明确知道哪段能跳 |
| ③ | **图必须自解释** | 每张图自带 `标题 + 卡点标注 + 一句结论`，**单独看懂，不依赖旁边文字** |
| ④ | **台阶/订正页的空位必须由题干唯一确定** | 空位前必须给出**具体函数式或数字**。只写「$x=-\dfrac{b}{2a}=$____」却不给 $a,b$，孩子无从作答 —— 那是废题，不是台阶 |
| ⑤ | **禁止文字墙** | 连续大段纯文字**必须有图或分点** —— 那是他一定会跳过的部分 |

**类比口诀的四件套**：① 他的直觉卡点（原话）→ ② 类比（一句话讲透为什么）→
③ 固定动作口诀（动词开头、照做就行）→ ④ 严格推导（回到定义/公式）。

> **类比的红线**（违反即不得写）：不得用负面事项（事故/疾病/赌博/作弊…）作类比；
> 不得调侃任何明星、角色、品牌、老师、同学；不得拿他自己开涮；
> **一次只用 1 个类比**、类比 ≤3 行；类比里的**数字必须与题目一致**。
> 详细规则见 [`references/detail-rules.md`](references/detail-rules.md)。

## 六、发布前自检清单

- [ ] **每一处"⚠️ 不确定处"都有家长的明确回复**（没有 → 不许写进错因）
- [ ] **错因只用两层口径**的取值，且**每条都能指回卷面原句**
- [ ] **不误写"已掌握 / 全部攻克"**（做对 ≠ 掌握）
- [ ] 数值/结论正确但过程错 → 记「**结果正确 · 思路错误**」，**不得**记成"正确"
- [ ] 详解**第一屏**是总览卡；**只看第一页也成立**
- [ ] 有图的题：图内**没有答案/推导**、中文不缺字、图与文字**不重叠**
- [ ] **三处同源**（详解 / 台账 / 看板 的错因逐字一致）
- [ ] **答案不进任何打印件**（详解是唯一例外）：题目版件的 PDF 文本层 `答案：`/`正解`/`解析` 必须 **0 处**（脚本扫，不靠肉眼）
- [ ] 生成命令**看了退出码**（`> log 2>&1; echo "exit=$?"`），**没有用管道吞掉退出码**
- [ ] **改过判定规则就造一个坏样本**，确认它真的会叫（"永远绿灯的自检"比没有自检更糟）

## 六·二、记录口径（两个容易漏的字段）

| 字段 | 口径 | 为什么 |
|---|---|---|
| **平均耗时** | 一律取**近 5 次**；不足 5 次用全部有效记录 | 防一次异常值带偏（一次考场紧张会把均值拉高一半） |
| **四象限** | 快+对 / 快+错 / 慢+对 / 慢+错 | **"会但慢"是弱基础的关键信号**，只看对错看不见它 |

> `快+错` 是**客观事实**，但"仓促"只是**可能解释**。归因必须先列可能原因（仓促/审题不足/概念混淆），
> 最终以过程与草稿为准 —— 孩子已有明显概念混淆时，**不得把"快"直接归因于粗心**。

## 七、脚本

`scripts/make_detail.py` —— 读一份 `detail.json`（题号 / 学生的 / 正解 / 错在哪 / 怎么改 /
本题本质 / 下一步 / 详版段落），产出**学生版详解 PDF**（第一屏总览卡 ＋ 详版）。

```bash
python3 scripts/make_detail.py detail.json 详解_学生版.pdf > log 2>&1; echo "exit=$?"
```

> **依赖排版引擎 `ws.py`**（中文禁则、行内公式、作答区）—— 与出卷技能 `math-paper-forge`
> **共用同一份**，本技能**不重复维护它**。脚本按此顺序查找：
> ① `$MATH_SKILLS_WS/scripts/ws.py`　② 同目录 `scripts/ws.py`　③ 同仓库 `../math-paper-forge/scripts/ws.py`。
> 找不到会**明确报错**，不会静默出半成品。
