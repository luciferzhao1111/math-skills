# 判卷规则全文

本文件按需加载。SKILL.md 里是梗概，这里是完整判据与历史事故。

## 一、判卷十步（顺序不可颠倒）

1. **判断结果**（对 / 错）。
2. **检查过程**：定义、推理链、**未经证明的前提**、关键步骤。
3. **定位错误步骤**（要能指到具体那一行）。
4. **两层错因**：`primary` ∈ {计算失误 / 概念混淆 / 思路卡壳}；动作缺失记 `modifier`；
   分不清标「待人工确认」。**必须给依据。**
5. **判断是否独立完成**（有没有提示 / 看过解析？）。
6. **更新独立复现**（未验证 / 通过 / 失败）。**看解析后做对 ≠ 独立复现通过。**
7. **更新迁移证据**（换数字/问法/情境，且独立完成、关键理由正确，才记通过）。
8. **记录实际用时**（计划 / 实际），并标 `快+对 / 快+错 / 慢+对 / 慢+错`。
9. **判断这题是"当前档判定题"还是"升档探测题"**。
10. **输出下一动作** ＋ 更新统计。

> **铁律**：只看客观作答。**数值/结论正确但过程错 → 记「结果正确 · 思路错误」**，
> 按概念混淆/思路卡壳归因，**不得记"正确"**。

## 二、两层错因：完整判据

### 判定顺序（**两步，不许合并成一句话**）

**第一步 · 判 `primary`（三选一）**
- **不会** → `概念混淆`
- **会、也知道要做什么、就是不知从何下手** → `思路卡壳`
- **思路方法都对、只是算错** → `计算失误`

**第二步 · 判 `modifier`（可缺省）**
独立问一句：「**那个例行动作，做了没有？**」—— 会、但那个动作没做 → 记 `习惯性漏步`
（**主类仍按第一步的 primary**）。

> **为什么必须拆两步**：旧写法把"会、但没做那个动作 ＝ 习惯性"与三个 primary
> **并列**，读起来像第四类根因，与"`习惯性漏步` 是 modifier"**自相矛盾**。

### `error_modifier` 词表（**封顶 5 个，禁止扩张**）

| modifier | 含义 | 该插入的检查步骤 |
|---|---|---|
| `习惯性漏步` | 该做的例行动作没做 | 增加一次"流程动作复现" |
| `边界遗漏` | 端点 / 开闭区间 / 取等条件没查 | 增加边界条件检查 |
| `定义域遗漏` | 没先写定义域 | 增加定义域检查 |
| `未做回代` | 算完不回代验算 | 增加回代 / 验算动作 |
| `分类不完整` | 该分类讨论的没分全 | 增加分类完整性检查 |

### 两层相加（**不是二选一**）

```
处置 = base_action(primary) ＋ modifier_action(error_modifier)
```

- `primary` 决定**主修复动作**（计算失误→同类重算 / 概念混淆→回课本澄清＋闭卷复述 /
  思路卡壳→补台阶＋同母题重做）。
- `modifier` 决定**是否在已有动作内插入一个检查步骤**（**嵌在同一次动作里，不另占时间**）。

> **为什么拆两层**：原方案把"习惯性"当第四个根因，会碰到
> **同一道错题既属"概念没内化"、又属"动作缺失"的二选一困境**。
> 两轴分开后，`概念混淆 ＋ 分类不完整` 可以同时成立。

### 几个必须守住的边界

- **`primary` 只能取三值、`modifier` 只能取五值**。任何修辞化标签
  （"系数配凑失误""概念死穴""考场战略失误"）**必须归入两层口径并改写**。
- **"待人工确认"是状态**，不是第四类根因。
- **"能说明" ≠ "能调用"**：事后能解释，不证明当时能独立调用 →
  归 `概念混淆 / 思路卡壳`，**不归 `习惯性`**。
- **审题类失误不新增错因值**：如"把'恰有一人'看成'至少一人'"，仍归
  `概念混淆`（辨析不清）或 `思路卡壳`（不会下手），允许加括号限定词。
  **禁止**另立"审题失误"这类新根因。
- **"粗心"不是错因，是"动作缺失"**。判据＝**能独立说明并能调用**该知识点的规则
  （先把概念问一遍，再要求他**不看提示、独立调用一次**），但题目里那个"例行动作"没出现。
- **策略类问题不记错因**（如"该跳的题没跳"）：记 `error_type = —` ＋ 策略标签，
  防止策略问题污染错因统计。

## 三、冻结机制（观测不可信时宁可不记）

**触发条件（任一即成）**：
1. 同一处**两次读法冲突**；
2. 卷面有**涂改/修正带覆盖**且家长未确认；
3. 家长报告的答案与 AI 读图**不一致**。

**处置**：标 ⚠️ 回问家长，并**冻结该题全部计算** ——
不判对错、不记错因、不改统计、不更新用时与连对。确认完成后再整体重算。

> **待人工确认 ≠ 失败**，也**不得**先记成"探测失败"。

### ⚠️ 为什么这条是铁律（事故记录 · 三条）

1. **两次读法冲突，选错了一边**：一份卷的某题，试卷照片读成 `3/5`、草稿纸读成 `1`，
   我**择了"看起来更合理"的那个**，判错。家长确认：实际是 `1`。
   → **冲突本身就是"读不准"的信号，必须回问，不得择一采信。**

2. **两次读法一致，仍然是错的**：某题的结果，两次读图（第二次还专门追问
   "分母是 3 还是 2"）**都读成 √3/2**，家长确认实际写的是 **√3/3**（正解）。
   → **"两次一致"不等于"正确"。** 凡涉及对/错分界的读图判定（尤其分数分母、
   涂改与否），**无论两次是否一致，都必须交家长过目**。

3. **凭印象虚报涂改**：我报了"某题答案是 155（原 2046 被划掉）"，
   而她写的就是 2046、**根本没有划掉**。
   → **未见涂改时不得加入涂改。** 这是高危推断，绝不能凭印象写。

## 四、三处同源

同一道题在**详解 / 台账 / 看板**里的错因必须**逐字一致**；改一处必须同步另两处。

> 事故来源：同一道题在三个文件里出现过三种错因写法，回溯时无法判断哪个是最终口径。

## 五、语言纪律

- **只用四档证据描述掌握程度**：`本轮通过` / `即时独立复现通过` / `延迟复现通过` / `已确认掌握`。
- **禁用**"全部攻克""已掌握"这类断言 —— **做对 ≠ 掌握**。
- **结果正确但过程错**，一律按概念混淆/思路卡壳归因，**不得**记成"正确"。
